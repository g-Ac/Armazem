# Glossário — o que é cada ferramenta

Os termos que aparecem neste projeto, em 1–2 linhas.

- **React** — biblioteca pra construir as telas (a interface) na web.
- **React Router (v8, framework mode)** — organiza as páginas e cuida do "vai e volta" entre a tela e o servidor. Cada página é uma **rota**.
- **loader** — função que **lê** dados antes da página aparecer.
- **action** — função que **grava** dados (ex: quando envia um formulário).
- **Vite** — roda o projeto no seu PC e monta a versão final (o "build"). É rápida.
- **Tailwind CSS** — estilo (cores, espaçamento) escrito como "classes" direto no HTML.
- **TypeScript** — JavaScript com "tipos", que pega erros antes de rodar.
- **Prisma** — a ponte entre o código e o banco (você escreve no lugar de SQL na mão).
- **SQLite** — um banco de dados simples, guardado num **arquivo** (`dev.db`). Zero instalação.
- **migration** — o registro de uma mudança no banco (ex: criar a tabela Note).
- **Biome** — confere o estilo do código e formata (tudo numa ferramenta só).
- **Vitest** — roda os testes automáticos.
- **`.env`** — arquivo com segredos/config (senhas, chaves). Nunca vai pro GitHub.
